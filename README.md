## Project Description
This project is a simple C program for managing basic information about a university cybersecurity laboratory. It calculates the costs of computers, network devices, and security software and displays the total lab investment.

## Input
The program asks the user to enter:

- Lab name
- Number of computers
- Number of network devices
- Number of security tools
- Cost per computer
- Cost per network device
- Annual security software cost

## Processing
The program performs the following calculations:

Computer Cost = Number of Computers × Cost per Computer

Network Cost = Number of Network Devices × Cost per Network Device

Total Lab Investment = Computer Cost + Network Cost + Software Cost

## Output
The program displays a formatted cybersecurity laboratory report containing the lab information and calculated costs.

## How to Compile
Open a terminal in the folder containing the program and use:

gcc cyber_lab.c -o cyber_lab

Then run the program using:

./cyber_lab
